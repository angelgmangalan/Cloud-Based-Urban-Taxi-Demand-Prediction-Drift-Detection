# Adaptive Cloud-Based-Urban-Taxi-Demand-Prediction-Using-Streaming-Data-and-Drift-Detection

Group project: Angel George, Athulya Mannambath, David S Louis.

The system predicts NYC taxi demand per zone and 15-minute interval. It uses Apache Spark for distributed processing, Apache Kafka and Spark Structured Streaming for real-time simulation, and compares three retraining strategies: a static model, a periodically retrained model and a drift-triggered adaptive model (ADWIN / Page-Hinkley).
